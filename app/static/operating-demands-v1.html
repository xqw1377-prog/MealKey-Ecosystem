现在发生什么了？

异常、利润、订单、评价、竞品。

为什么？现在该怎么办？

Diagnosis + Next Best Action。核心是第 50 问：今天只该做哪一件事。

能不能替我做？有没有用？

Execution → Result → Strategy Memory。

契约链：Demand → Trigger → Business Truth → Playbook → Actions → Profit/Risk Gate → Execution → Metric → Observation → Result → Memory
