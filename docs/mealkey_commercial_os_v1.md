# MealKey Commercial OS V1.2（战略收口 2026-08-13）

定价数字不变。竞争战略已冻结为 V1：平台是执行场，MealKey 是商家的经营控制层。

**定位：** 一个站在商家这一边、跨平台经营并持续从结果里学习的 AI 外卖店长。系统名：Merchant Operating Control Plane。

**护城河：** Business Truth + Outcome Data + Strategy Memory。跨平台是入口，不是资产本身。100 条闭环是 PMF Evidence Seed，不是护城河。

**不要再写：** 平台 AI 只会建议，我们会执行。也不要写「不争场内执行所以可以不写回」。

**战略位：** 不跟平台争谁更懂平台，争谁更懂老板整盘生意。

## 公司目标（Production Evidence）

**20 Paid Stores / 100 Verified Closed Loops / 10 Memory-Changed Decisions / 1 Natural Renewal / 真实 AI Cost per Store**

这比「V1 开发完成」更重要。100 条闭环证明系统不是假的；10 次记忆改判断才证明 Strategy Memory 不是装饰品。

20 家必须同时测 Product / Price / Compute / Distribution，分成四个 Cohort：直营 5、转介绍 5、Partner 5、连锁扩店 5。至少一部分真正付钱。

## ¥300 卖什么

卖持续经营责任，不卖 AI 分析/诊断/报表/聊天。

五项 SLA：每天有人看；重要问题有人判断；该做什么有人推动；做完以后有人回来检查；成功失败都会成为下一次经验。

## 三本账

| 阶段 | 收入 | 前提 |
| --- | --- | --- |
| V1 Subscription | ¥300/店/月 + AI 算力（真实成本 ×1.30） | 现在。不承诺利润增量 |
| V2 + Execution | 执行托管 | 权限成熟 |
| V3 Optional Outcome Share | 增值分成 | Attribution 被证明以后 |

V1 **不加**利润增量共赢。白标 ERP/POS **不是**第一战略。

## 合伙人

首年基础 50% 先结。+5%～20% 只认 **90-Day Qualified Store**。最高 70%。Y2 30%、Y3 20%、Y4+ 10%。AI 算力不分润。只认单层 Partner → 直接客户。自有门店不算推荐业绩。

拉来 300 家一个月全退，拿不到 70%。

## 增长优先级

P0：直营产品 + Partner 分销；人工辅助 Closed Loop（藏在产品后）；跨平台统一经营。
P1：执行托管。
P1/P2：Embedded/API（跑出真实店以后）。
P2：Result/利润分成。
P3：Strategy/Data 产品。

数据通道：Official API → Service Provider API → CSV/Excel → 报表/截图 → 商家确认。全部进入同一个 StoreState。
