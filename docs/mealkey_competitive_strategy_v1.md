# MealKey Competitive Strategy V1

冻结日 2026-08-13。政策真相源：`app/services/commercial/policy.py`。冻结页：`/competitive-strategy`。

## 冻结句

**平台是执行场，MealKey 是商家的经营控制层。**

站在这家商户整体利润和长期经营目标上，现在整盘生意最该做什么？

对用户叫 AI 外卖店长。对公司，它是 **Merchant Operating Control Plane**。下面接美团 / 淘宝闪购 / 京东 / 抖音 / POS / ERP / 成本 / 老板输入 / 竞品数据。上面只有商家经营目标。平台越多，MealKey 价值越大。

## 三处修正

1. **不争场内第一 ≠ 放弃场内执行。** 必须走完 Decision → ActionSpec → Platform Action → Read Back → Result。V1 最低三条：普通评价回复、商品标题、商品主图。
2. **100 Verified Closed Loops 是 PMF Evidence Seed，不是护城河。** 0–100 证明系统不是假的；真正的 moat 是不同类型门店 × 真实状态 × 真实 Action × 长期 Result → Strategy Library。
3. **第五战场：Cost of Intelligence。** 不是谁调用最强模型最多，而是谁能用更少 AI 成本做出更高价值的经营判断。

## 五大战场

| 战场 | MealKey 战略 |
| --- | --- |
| 场内数据与执行 | 够用，不争全面第一 |
| 跨平台整盘生意 | 必须领先 |
| 经营闭环与记忆 | 核心领先区 |
| 商业牵引 / 分发 | 当前必须补齐 |
| 单位智能成本 | 规模化生死线 |

## Production Evidence

- 20 Paid Stores：证明商业
- 100 Verified Closed Loops：证明经营闭环
- 10 Memory-Changed Decisions：证明学习飞轮
- 1 Natural Renewal：证明价值不是新鲜感
- 真实 AI Cost / Store：证明单位经济可以扩张

## 六句冻结

1. 不跟平台争谁更懂平台，争谁更懂老板整盘生意。
2. 跨平台是进入市场的楔子，不是长期护城河。
3. Business Truth 是决策基础，Outcome Data 是核心资产，Strategy Memory 是复利。
4. Agent、Runtime、长程任务、单平台自动化都不是长期壁垒。
5. 第一阶段不追求功能最多，而追求最多真实 Closed Loop。
6. 架构领先只有经过付费门店、真实动作和真实结果之后，才会转化成公司壁垒。

下一件事：尽快把设计优势转化成真实 Outcome Data 优势。
